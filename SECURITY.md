# Security Policy

## Supported Versions

| Project Component | Supported Versions | Status |
| ----------------- | ------------------ | ------ |
| PHP-Hardening-Kit Runtime Guard | 1.x.x | ✅ Supported (PHP 5.4 to 8.4+) |
| `php-hardening-check` CLI | 1.x.x | ✅ Supported |
| Backported C-patches | PHP 5.4 - 8.1 | ✅ Actively maintained |

## Reporting a Vulnerability

If you discover a security vulnerability or bypass in PHP-Hardening-Kit:

1. **Do not open a public issue.**
2. Send an email with reproduction steps and proof-of-concept to the author or submit a confidential advisory via GitHub Security Advisories.
3. You will receive a response within 24 hours. Once verified, a hotfix patch and release will be issued.
